# Key Expressions Generator - 기획서

## 한 줄 요약
**한국어 학습 스토리북의 "Key Expressions" 페이지를 자동 생성하는 Figma 플러그인**

---

## 누구를 위한 제품인가?
- **PronounceKorean** 소속 한국어 교육 콘텐츠 제작자/디자이너
- 스토리북 형태의 한국어 학습 교재를 만드는 사람

## 어떤 문제를 해결하는가?

### Before (수동 작업)
- Figma에서 빈 카드 하나하나 수동 배치
- 한국어/영어 텍스트 따로 입력
- 적절한 일러스트 이미지 직접 찾아서 넣기
- 내용 수정 시 → 카드 위치 수동 재배치
- **소요 시간: 페이지당 수 시간**

### After (플러그인 사용)
- 한국어 표현만 입력 → 레이아웃 자동 생성
- 번역 원클릭 (AI)
- 이미지 일괄 생성 (AI, 스타일 참조 가능)
- 텍스트 수정 → 실시간 리플로우 (이미지 유지)
- **소요 시간: 페이지당 10~15분**

---

## 핵심 기능 목록

### 1. 텍스트 입력 & 파싱
- 메인 텍스트 영역에 한국어 표현 입력
- **엔터 1번** = 같은 카드 내 줄바꿈
- **엔터 2번** (빈 줄) = 새 카드
- **엔터 3번+** (빈 줄 2개 이상) = 새 카드 + 강제 줄바꿈 (새 행 시작)
- 파싱된 카드 수 실시간 표시 ("Parsed: N cards")
- 최대 32장 권장 (초과 시 경고)

### 2. 레이아웃 자동 생성
- "Generate Layout" 클릭 → Figma 캔버스에 완성된 카드 그리드 생성
- **2페이지 스프레드** 구조 (7452×3780px)
- 페이지당 8×8 셀 그리드, 카드는 기본 2×2 셀 크기
- 텍스트 길이에 따라 카드 크기 자동 조절 (가로/세로 확장)
- "Key Expressions" 타이틀 배너 자동 생성
- 페이지 중앙 가이드라인 표시

### 3. 실시간 업데이트
- 스페이스바 또는 더블 엔터 시 즉시 캔버스 반영
- 400ms 디바운스로 타이핑 중 렉 방지
- **이미지 보존**: 텍스트 수정해도 기존 이미지 유지
- 카드 순서 변경해도 이미지가 올바른 카드를 따라감

### 4. AI 번역 (한→영)
- "Translate" 클릭 → Gemini AI가 영어 번역 생성
- 맥락 기반 주어 추가, 대문자 처리, 관사 규칙 등 적용
- 이미 번역된 카드는 건너뜀
- 개별 카드 재번역도 가능

### 5. AI 이미지 생성
- "Generate Images" 클릭 → 표현당 2개 변형 이미지 일괄 생성
- **레퍼런스 스타일**: 캔버스의 "ref_img" 프레임을 참조해 동일한 화풍으로 생성
- 진행률 바 + 취소 기능
- 분당 10건 제한, 자동 재시도 (최대 5회)

### 6. 이미지 관리 (Images 탭)
- 썸네일 갤러리로 모든 변형 이미지 확인
- 클릭으로 카드에 적용할 이미지 교체
- "+Regen" 버튼으로 커스텀 프롬프트 입력 후 추가 변형 생성
- 기존 이미지는 보존, 새 변형이 추가됨

### 7. 개별 카드 편집
- Figma에서 카드 하나 클릭 → 카드 상세 뷰 표시
- 해당 카드의 이미지 목록 확인 및 교체
- 개별 재번역/이미지 재생성 가능

### 8. 멀티 페이지
- "+ New Page" 클릭 → 기존 프레임 아래에 새 프레임 생성
- 이미지 저장소 공유 → 같은 표현은 같은 이미지 사용
- 번역/이미지 ID가 통합 관리됨

### 9. 데이터 복원
- 기존 KeyExpr 프레임 선택 시 → 모든 데이터 자동 복원
  - 텍스트, 번역, 이미지, 선택 상태 모두 복구
- 삭제 후 재입력해도 같은 표현이면 이미지/번역 재연결

### 10. 설정
- Gemini API 키
- 배경색 (기본: #FFCF66 노란색)
- 폰트 종류 (기본: NanumSquareRound)
- 폰트 크기 (8~200px, 기본: 100px)
- 레퍼런스 프레임 이름 (기본: "ref_img")
- 유틸리티: 임시 노드 정리, 가이드 추가/제거, 스토리지 초기화

## 카드 구조 (생성되는 결과물)

```
┌──────────────────────┐
│                      │
│    [AI 일러스트]      │  ← 카드 높이의 67%
│    흰 배경 + 주황 테두리 │
│                      │
├──────────────────────┤
│   고양이              │  ← 한국어 (굵은 글씨, 큰 사이즈)
│   Cat                │  ← 영어 (회색, 작은 사이즈)
└──────────────────────┘
```

---

## 스마트 ID 시스템 (핵심 설계)
- 각 한국어 표현에 고유 숫자 ID 부여
- **같은 표현 = 같은 ID** → 삭제 후 재입력해도 이미지/번역 유지
- 번역, 이미지 선택, 이미지 변형 모두 이 ID에 연결
- 여러 프레임에서 공유 가능

---

## 사용 시나리오 (전체 플로우)

1. 플러그인 열기 → Settings에서 API 키 입력
2. 한국어 표현 입력 (줄바꿈으로 카드 구분)
3. **Generate Layout** → 카드 그리드 자동 생성
4. **Translate** → 영어 번역 자동 추가
5. **Generate Images** → AI 일러스트 일괄 생성
6. Images 탭에서 마음에 안 드는 이미지 교체/재생성
7. 텍스트 수정 시 실시간 반영, 이미지 유지
8. 필요 시 **+ New Page**로 추가 페이지 생성
9. 완성된 프레임을 Figma에서 내보내기
