# Key Expressions Generator - Figma Plugin 기획서

## 개요
PronounceKorean 한국어 학습 동화책의 "Key Expressions" 페이지를 자동 생성하는 Figma 플러그인.
표현 텍스트 입력 → AI 이미지 생성 → 레이아웃 자동 배치를 원스톱으로 처리.

레퍼런스: `resources/keyexpressions_ref.png`

---

## 확정 스펙

| 항목 | 값 |
|------|-----|
| 프레임 크기 | 7452 x 3780 (펼침면) |
| 배경색 | #FFCF66 (기본, 변경 가능) |
| 그리드 | 4x4 / 반페이지 (양면 최대 32칸) |
| AI 모델 | gemini-3.1-flash-image |
| API 호출 | 클라이언트 직접 (프로토타입) |
| 이미지 | 표현당 2벌 벌크 생성 |
| 폰트 | Figma 기본 + 유저 커스텀 가능 |
| 텍스트 규칙 | 싱글엔터=카드내 줄바꿈, 더블엔터=새 카드 |
| 넓은 카드 | 텍스트 초과 시 2칸, 빈칸 자연스럽게 남김 |

## 유저 워크플로우

### 1. 설정
- Gemini API 키 입력
- 배경색 선택
- 레퍼런스 프레임 이름 지정 (스타일 참조용)
- 폰트 지정 (선택)

### 2. 텍스트 입력
```
고양이
도마뱀

동물

하얀색 = 흰색
분홍색 = 핑크색

원피스를 입은
고양이
```

### 3. 레이아웃 생성
- "Generate Layout" 클릭
- 프레임 + 제목 + 가이드라인 + 카드 그리드 자동 생성
- 카드: 흰색 라운드렉트, 상단 75% 이미지, 하단 25% 텍스트

### 4. AI 이미지 벌크 생성
- "Generate All Images" 클릭
- 레퍼런스 프레임 스타일 참조
- 표현당 2벌 × 32표현 = 최대 64장
- 진행률 실시간 표시
- 첫 이미지 자동 카드 배정

### 5. 이미지 리뷰 & 교체
- 갤러리에서 표현별 썸네일 확인
- 다른 변형으로 교체 (Swap)
- 마음에 안들면 프롬프트 수정 후 재생성 (Regen)

## 기술 아키텍처

### Figma 플러그인 2레이어 구조
- **Sandbox (code.ts)**: Figma API 접근, 네트워크 불가
- **UI (React iframe)**: 네트워크 가능 (Gemini API 호출), Figma API 불가
- **통신**: postMessage로 데이터 교환

### 핵심 데이터 흐름
```
텍스트 입력 → 파싱 → UI에서 Sandbox로 레이아웃 요청
                    → Sandbox가 Figma에 카드 그리드 생성

이미지 생성 → UI에서 Gemini API 호출 → base64 이미지 수신
           → UI에서 Sandbox로 이미지 전달
           → Sandbox가 figma.createImage()로 카드에 삽입
```

### Rate Limiting
- 토큰 버킷 (RPM 설정 가능, 기본 10)
- 동시 3개 요청, 429시 자동 일시정지
- 취소 지원 (AbortController)

## 구현 단계

1. **프로젝트 셋업 + 정적 레이아웃** - Vite 빌드, 프레임/그리드 생성
2. **텍스트 파싱 + 스마트 레이아웃** - 엔터 규칙, 넓은카드, 폰트
3. **Gemini API 연동** - 단일 이미지 생성 테스트
4. **벌크 생성 + 저장소** - rate limiter, 진행률, 자동배정
5. **이미지 관리 UX** - 갤러리, 교체, 재생성
6. **마무리** - 에러처리, temp 삭제 유틸, 엣지케이스
